## 1. Install and connect your agents

```bash
curl -fsSL https://www.chofito.dev/astrograph/install.sh | sh
astrograph install
```

`astrograph install` registers the MCP server and the Astrograph skill with Claude Code, Cursor,
Codex and opencode. See [MCP & skills](/docs/mcp).

## 2. Index a project

```bash
cd my-project
astrograph init
```

This creates `.astrograph/` (the SQLite graph plus its own `.gitignore`) and indexes every
supported file git knows about. A few thousand files take a few seconds.

## 3. Ask questions

```bash
astrograph context "how does checkout work"
astrograph search Cart
astrograph callers CartService.addItem
astrograph impact "App\Models\Order::total"
astrograph trace CheckoutPage PaymentGateway.charge
```

Every query re-syncs changed files first, so the answers match your working tree. To bring the
index up to date explicitly, run `astrograph index`; `astrograph index --force` rebuilds it.

## 4. Check the result

```bash
astrograph status
```

Status shows how many references were linked to a project symbol, how many leave the project
(libraries, builtins), how many could not be pinned down, and which files failed to parse.
