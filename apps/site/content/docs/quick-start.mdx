Get from zero to a queryable code graph in a couple of minutes.

## Install the binary

```bash
curl -fsSL https://www.chofito.dev/astrograph/install.sh | sh
```

Make sure `~/.local/bin` is on your `PATH`. Details: **[Install](/docs/install)**.

### Optional: configure agent hosts

```bash
astrograph install
```

This writes MCP config and the agent guide into Claude Code, Cursor, Codex, or opencode.
It does **not** install the binary — that is the curl step above.

### Contributors (from source)

```bash
bun run build
bun run install:local
```

## Index a project

From the root of a repository (JS/TS gets full semantic enrichment; PHP is indexed structurally):

```bash
astrograph init
```

This creates a local `.astrograph/` directory (the SQLite graph, config, and watcher metadata) and
runs the first full index. Re-running stays incremental — only changed files are re-extracted.

## Run your first queries

```bash
# find symbols
astrograph search useAccount

# build task context (entry points + relevant code + coverage)
astrograph context "how does session refresh work?"

# call flow
astrograph callers useAccount
astrograph callees AuthProvider

# blast radius before a change
astrograph impact AuthProvider

# how does one symbol reach another
astrograph trace login refreshToken

# index health
astrograph status
```

## Keep it fresh

Astrograph watches the project and re-syncs changed files automatically. You can also reconcile on demand:

```bash
astrograph sync
```
