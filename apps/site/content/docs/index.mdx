Astrograph indexes a repository into a **local graph of declarations and references** — classes,
functions, methods, calls, instantiations, inheritance, JSX renders — stored in SQLite. It exposes
that graph through a **CLI** and an **MCP server**, so coding agents (and you) can ask structural
questions instead of grepping.

## Why

Agents waste most of their context finding code: search, open a file, search again. Astrograph
answers "who calls this", "what breaks if I change it" or "how does checkout work" in one call,
with the relevant source attached.

## How it works

1. Files come from `git ls-files` (respecting `.gitignore`), filtered to `.ts .tsx .mts .cts .js .jsx .mjs .cjs .php`.
2. Each file is parsed with tree-sitter into symbols, references and imports.
3. A linking pass resolves every reference through imports, re-exports, `tsconfig` paths,
   PHP namespaces and `use` imports, and declared types.
4. Every reference is labeled `exact`, `inferred`, `ambiguous`, `external` or `unresolved`.

Only changed files are re-parsed. The MCP server re-syncs before every call, so there is no
daemon or watcher to manage.

## Principles

- **Local only.** No network, no telemetry, no LLM calls.
- **Honest.** Unproven links are labeled, not guessed.
- **Small.** One binary, one SQLite file per project.
