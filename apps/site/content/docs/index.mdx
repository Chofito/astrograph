Astrograph indexes a repository into a **local graph of symbols and relationships** — functions,
classes, imports, exports, calls, inheritance, references — stored in SQLite. It exposes that graph
through a fast **CLI** and an **MCP server**, so humans and coding agents can ask sharp structural
questions instead of grepping blindly.

## Why it exists

Most coding workflows start with text search. It works, but it is noisy and shallow:

```bash
rg "useAccount"
rg "AccountService"
rg "login"
```

Astrograph builds the semantic map **once**, locally, then answers precise questions:

```bash
astrograph callers useAccount
astrograph trace login refreshToken
astrograph context "how does session refresh work?"
```

## What makes it different

Astrograph uses a **modular extraction pipeline**:

- **Pass A — tree-sitter** for fast structural symbols, in every language that has a backend.
- **Pass B — language enrichers** for semantic depth where available. JS/TS ships with the
  **TypeScript Compiler** enricher (compiler-backed module resolution, aliases, inheritance, and re-exports, while retaining unresolved or ambiguous evidence).

Two backends ship today: **JS/TS** (`.ts` `.tsx` `.mts` `.cts` `.js` `.jsx` `.mjs` `.cjs`) with the Compiler enricher, and **PHP**
(`.php`) with a name-resolution enricher (heritage, types, calls). A language without an enricher still gets a real, queryable graph — its
edges are marked `tree-sitter` rather than `ts-compiler`, so you can see exactly how much they prove.
A file type no backend claims is not indexed; `astrograph status` tells you which are active.

The result contract has explicit `external`, `unresolved`, `ambiguous`, and `partial` states instead of
forcing every relation into a resolved target. Current global-query honesty gaps remain documented and
should be considered before turning an empty result into an absence claim.

## Principles

- **100% local.** No API keys, no external services — everything lives in `.astrograph/`.
- **Incremental.** A file watcher keeps the graph fresh by re-indexing only what changed.
- **Honest.** Coverage, freshness, and resolution confidence are first-class in every answer.
